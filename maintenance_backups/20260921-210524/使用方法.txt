完整说明看：~/smartcar/交接说明.md
代码母本：~/smartcar/docker/overlay/   （目录说明见该处 README.md）

开启可视化：
xhost +local:
sudo docker start smartcar-sim
# 若容器不存在，用原来的 docker run（见交接说明 / 旧记录）

打开 Gazebo：
sudo docker exec -e DISPLAY=:0 -e LIBGL_ALWAYS_SOFTWARE=1 smartcar-sim \
  bash /home/hajimi/smartcar_2026_ws/scripts/start_gzclient.sh

打开 RViz：
sudo docker exec -e DISPLAY=:0 -e LIBGL_ALWAYS_SOFTWARE=1 smartcar-sim \
  bash -lc 'source /opt/ros/kinetic/setup.bash; source ~/smartcar_2026_ws/devel/setup.bash; rviz -d ~/smartcar_2026_ws/src/smartcar_sim/config/inspection.rviz'

键盘（焦点在 Gazebo，不要在 RViz 按 WASD）：
sudo docker exec -it -e DISPLAY=:0 smartcar-sim bash ~/smartcar_2026_ws/scripts/keyboard.sh

定位（开源 laser_scan_matcher + AMCL）：
bash ~/smartcar/scripts/restart-localization.sh
然后在 RViz 做 2D Pose Estimate

小车回起点：
bash ~/smartcar/scripts/reset-to-start.sh

改参数（宿主机改，再拷进容器）：
nano ~/smartcar/config/localization.yaml
sudo docker cp ~/smartcar/config/localization.yaml \
  smartcar-sim:/home/hajimi/smartcar_2026_ws/src/smartcar_navigation/config/localization.yaml
bash ~/smartcar/scripts/restart-localization.sh

进容器：
sudo docker exec -it smartcar-sim bash
