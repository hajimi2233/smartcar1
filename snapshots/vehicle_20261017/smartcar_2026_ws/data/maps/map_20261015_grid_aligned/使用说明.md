# 栅格方向对齐的地图

从已修正直角并恢复左侧短墙的1cm版本生成。栅格方向顺时针调整16.5度，使六面通道墙在PGM像素网格中竖直，左侧短墙水平。墙体几何未整体移位或按新厚度重建，外框保留原扫描起伏。

文件：根目录 `map.pgm`、`map.yaml` 是1cm版；`navigation_5cm/map.pgm`、`navigation_5cm/map.yaml` 是5cm版。文件必须配套搬运。源文件保留在上一版本目录，没有覆盖。

这次不是只旋转图片。同步换算YAML原点与方向：

```yaml
origin: [-10.645607267833867, -4.3695206318173385, 0.2879793265790644]
```

最后一项为弧度，约16.5度，不能擅自改为0。它使重定向后的格子仍对应原来map坐标系中的墙体位置。ROS/RViz按这个角度显示地图时，场地在map坐标下仍可能整体倾斜；PGM图已端正，通道墙边界不再交替跳格。

5cm版尺寸311×182，六面通道墙体中段的左右边界各只有一组固定列坐标，通过逐行一致性检查；没有原先倾斜墙产生的阶梯。端部仍有5cm量化误差，外框原有扫描波动仍可能呈不规则边缘。使用保守占用转换，碰到墙的格子判为占用，本版六面墙的栅格占用宽度为5格即25cm；不等于将实际墙厚重新标定成25cm。

图像像素中心、原点平移和旋转换算保持同一参考约定。七个矩形的全部几何角点经新旧YAML换算后，世界坐标差小于1e-10m（浮点误差），这验证坐标变换本身，不表示地图或定位有该测量精度。1cm旋转和5cm栅格化仍有离散边界误差。

当前仅生成电脑端文件，没有自动替换车端默认地图或重启定位、导航。车端使用前应先复制文件，停车并退出导航/定位后切图，再重新初始化并核对扫描。复用旧低代价线和巡检点前也需核对，不能只凭原点补偿就跳过实际检查。
