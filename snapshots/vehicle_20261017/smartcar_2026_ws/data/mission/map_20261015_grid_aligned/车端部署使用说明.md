# 新地图16点部署使用说明

16点和两条低代价线已保存到车端。通用点位文件已更新；旧地图记录、旧patrol-map12入口保留。部署没有发目标、没有加载巡检队列、没有停止或重启导航。

停稳后用户自行退出旧导航，再运行 `~/nav`；新点由已有显示节点读取，两条线按当前地图绑定键恢复。仅保存文件不会改变当前正在执行的路径。

新地图入口为 `~/patrol-map15`，不要把旧 `~/patrol-map12` 当成当前图的入口。

```bash
# 只看默认全A路线及朝向，不加载、不行驶
~/patrol-map15 preview
# 手动刷新16点显示；若已重启nav则通常无需另开
~/patrol-map15 marks
# 只预览同侧B1、B3、B5、B7、B9
~/patrol-map15 preview-bslide
# 加载这5个同侧B点，保持终端；此时不行驶
~/patrol-map15 bslide
# 另一终端由用户手动开始
~/patrol-map15 run
# 取消队列
~/patrol-map15 cancel
```

完整巡检仍可用 `~/patrol-map15 load 描述`。描述沿用每个通道“正常/异常A/B＋类别1～4”的10段格式；未提供描述时默认10个A1。`load`仅加载，运行仍需单独 `run`。已有队列时先取消并退出旧队列终端，再加载新队列。

本次离线验证是上下两排同侧40组标准位姿点对，不代表任意A/B完整顺序和返回终点已进行实车验证。标记点均为前轴中心，后轴前方0.62m。推荐起终点沿蓝线方向停车。
